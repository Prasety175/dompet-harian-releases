# Dompet Harian — rilis

Repo ini hanya berisi file APK rilis aplikasi **Dompet Harian** (Android), dipakai oleh tombol
**Profil → Cek update** di dalam aplikasi. Kode sumber tidak disimpan di sini.

- Setiap APK ditandatangani dengan kunci rilis yang sama. Aplikasi menolak memasang APK
  dengan tanda tangan berbeda, dan Android juga menolak update seperti itu.
- Aplikasi tidak mengirim data keuangan ke mana pun; repo ini tidak menerima data apa pun dari aplikasi.
